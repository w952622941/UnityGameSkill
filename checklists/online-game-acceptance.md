# Unity 手机网游验收清单

这份清单验证“可玩、可恢复、可结算、可诊断”，不能只验证接口返回 200。记录 APK/AAB 摘要、Build GUID、客户端/服务端提交、协议/模拟器/内容版本和设备信息。

## 架构与安全边界

- [ ] 每个玩法已明确选择 Verified Local、Authoritative Realtime 或 Pre-settled Playback。
- [ ] 客户端只提交输入/证据，不直接提交可信伤害、掉落或奖励。
- [ ] 票据、租约、序号、幂等键和终局唯一约束已实现。
- [ ] 永久资产来自服务器账本；客户端余额只是投影。
- [ ] 没有密钥、令牌、数据库口令或共享签名秘密进入 APK/Git/DIAG。

## 确定性与回放

- [ ] 客户端和服务器对黄金票据/输入产生完全相同的检查点和最终哈希。
- [ ] 已覆盖集合顺序、舍入、RNG、序列化、空值和内容传输测试。
- [ ] 能报告首个分歧 Tick、客户端/服务器哈希和稳定拒绝码。
- [ ] Debug 与 Release 都通过正确性测试；性能结论来自 Release。
- [ ] 重复提交/Worker 重启不会重复结算。

## 输入与生命周期

- [ ] 摇杆按下、拖动、松开后正常，松开本地停止不超过 50 ms。
- [ ] `PointerCancel`、拖出、失焦、暂停、禁用、销毁都发送零方向。
- [ ] 连续 1000 次方向变化后邮箱仍有界，只保留最新状态和必要确认。
- [ ] 前后台、锁屏、来电/权限弹窗和低内存恢复不会遗留输入。
- [ ] 第一场退出后第二场的等级、HUD、技能弹窗、计时、生成器和终局状态完全重置。

## 弱网与重连

至少执行以下网络档位：

| 档位 | RTT/抖动/丢包 | 期望 |
| --- | --- | --- |
| N0 | 本地或稳定低延迟 | 功能基线 |
| N1 | 100 ms / 30 ms / 1% | 不丢终局、不积压输入 |
| N2 | 250 ms / 80 ms / 3% | 本地操作连续，可恢复 |
| N3 | 50–800 ms 变化 / 200 ms / 10% | 队列有界、无永久方向滞留 |
| N4 | 断网、重连、Wi-Fi/蜂窝切换 | 新租约接管，旧连接失效 |

- [ ] 重复、乱序、延迟包不会倒退 Tick 或覆盖新输入。
- [ ] 暂停快照后恢复不会瞬移到过期状态。
- [ ] 实时模式使用持久 WSS，而不是 20 Hz HTTP 轮询。
- [ ] N3 下服务器收到零方向 P95 不超过 2 秒、P99 不超过 4 秒；若项目采用更严目标，以项目目标为准。
- [ ] 网络恢复后续传证据/查询结算，不会另建重复战斗。

## 战斗与结算

- [ ] 计时、移动、刷怪、技能、升级、击杀和战斗金币同步推进。
- [ ] 胜利、死亡、主动退出、应用被杀和网络断开语义正确。
- [ ] 死亡/胜利后结果 UI 在终局确认后 2 秒内出现，资产刷新不阻塞 UI。
- [ ] 主动退出不走死亡结算；按规则决定是否奖励。
- [ ] 同一结算重试 100 次只产生一笔账本流水和一次终局。
- [ ] 返回主界面、重启客户端后余额与服务器账本一致。

## Android 真机矩阵

- [ ] API 22/23、26、29、31、33、35 中项目支持范围已覆盖。
- [ ] 至少一台无 GMS 华为真机通过，不把 Play Integrity 当唯一硬门槛。
- [ ] ARM64 IL2CPP 通过；目标图形 API、60/90/120 Hz 和异形屏通过。
- [ ] 不同 RAM 档位、Wi-Fi/蜂窝、温控降频和长时间战斗通过。
- [ ] 安装包签名、升级安装和干净安装均通过。

## DIAG 与运营

- [ ] DIAG 包含版本、设备、Tick、输入确认、租约、实体数、证据、哈希、验证、结算和阶段耗时。
- [ ] 游戏内报告可复制、可关闭，不遮挡后续操作。
- [ ] 报告已脱敏且不包含凭据。
- [ ] 权威事务写 Outbox，运营统计故障不影响结算。
- [ ] 事件带事实等级和关联 ID，可从运营指标追溯到战斗与日志。

## 发布门槛

- [ ] 所有阻断项有可复现证据和修复验证。
- [ ] 服务端 Release 容量、回放延迟和资源上限达到项目目标。
- [ ] 数据库备份已实际恢复验证。
- [ ] 固定域名、HTTPS/WSS、环境隔离和回滚演练完成。
- [ ] Quick Tunnel 仅用于临时验收，没有进入生产配置。

## 云服务器部署证据

- [ ] 已按 `../docs/cloud-game-server-deployment-runbook.md` 记录发布目录、镜像摘要、Compose 和回滚目标。
- [ ] 公网只开放经批准的 SSH、80/443；API 原始端口绑定回环，PostgreSQL 未暴露。
- [ ] ACME staging、生产证书和自动续期 dry-run 均通过。
- [ ] 已核对运行容器实际环境变量和镜像 ID，而不只检查静态 Compose 文件。
- [ ] HTTPS 200 之外，两种启用的战斗模式均执行了真实开局和终局/结算验证。
- [ ] 数据库备份已下载、校验并在隔离环境实际恢复。
